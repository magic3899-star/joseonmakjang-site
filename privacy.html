개인정보처리방침

「조선막장극장 업로더」(이하 "앱")는 채널 운영자 본인이 자신의 유튜브 채널에 영상을 올리고 관리하기 위해 만든 개인용 도구입니다. 시행일: 2026-11-07

1. 이용하는 Google 데이터

운영자 본인이 동의한 YouTube 권한(영상 업로드, 예약 공개, 제목·설명·자막·썸네일·재생목록 관리)만 사용합니다.

2. 수집·저장

앱은 운영자 본인의 컴퓨터에서만 실행되며, 인증 토큰도 그 컴퓨터에만 저장됩니다. 제3자 서버로 전송하거나 판매·공유하지 않습니다. 다른 사용자의 개인정보는 수집하지 않습니다.

3. Google API 사용 고지

앱의 Google API 정보 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(제한된 사용 요구사항 포함)를 준수합니다.

4. 권한 철회·문의

권한은 Google 계정 권한 페이지에서 언제든 철회할 수 있습니다. 문의: naverhome10@gmail.com
